# 《ASTRAL BLOOM — 星樱物语》抽卡 UI 精修提示词

用户 2026-11-17 ~17:24 CST 发送。用于优化现有抽卡界面的 UI，不改变原有布局和功能。

请基于现有的《ASTRAL BLOOM — 星樱物语》抽卡界面，对 UI 视觉进行高级化、简洁化和统一化设计。

重要：保留现有抽卡界面的整体布局、角色立绘、背景场景、卡池内容和功能位置。不要重新设计整个页面，不要生成新的场景，不要改变原有功能结构。本次工作的核心是提升 UI 的视觉品质，让界面更加干净、精致、专业，达到高品质商业二次元 RPG 游戏的 UI 水准。

## 一、整体 UI 风格

采用现代日系幻想 RPG 游戏 UI 设计语言。

整体风格以简洁、克制、优雅、清晰为核心。

参考高品质二次元游戏的界面排版方式，重点关注字体、间距、对齐、边框、按钮、信息层级和视觉节奏。

不要使用普通网页后台模板的设计方式。

不要满屏卡片，不要所有内容都塞进半透明矩形框。

不要过度使用玻璃拟态，不要制造大量悬浮面板。

UI 必须像真正游戏内的原生界面，而不是网页应用。

## 二、色彩规范

主要颜色：

深群青：#142B67
经典群青：#244DAB
星空蓝：#4169C9
月光蓝：#7897DB
月光白：#E5EAF7
银白：#C9D4E8
淡金色：#D9CBAA

整体以深群青和月光白为主要视觉色彩。

文字使用清晰的月光白、浅银灰和适量淡金色。

强调色只用于当前选中卡池、重要按钮、UP 标识和保底信息。

不要让粉色和紫色成为主导色。

## 三、布局与排版

保留原有抽卡界面的布局结构。

左侧卡池导航采用简洁的列表式设计，选中状态通过细线、色彩和轻微背景变化体现，不要使用厚重的大型卡片。

中间区域保留卡池名称、活动说明、角色介绍和祈愿信息。

右侧保留角色立绘，让角色成为界面的主要视觉焦点，不要让 UI 遮挡角色。

底部保留单抽和十连按钮，按钮尺寸适中，具有清晰的主次关系。

货币余额、保底次数和抽卡次数使用统一的数字排版，保证玩家可以快速读取信息。

所有元素保持统一边距、统一对齐方式和合理留白。

## 四、按钮设计

抽卡按钮采用简洁的高级幻想风格。

单抽按钮：深蓝色背景，银白色文字，细致边缘装饰。

十连按钮：采用更明确的强调色，视觉权重高于单抽按钮。

按钮需要有清楚的默认、悬停、按下、禁用状态。

按钮不要设计得过于厚重，不要使用廉价的高亮渐变、巨大光效和夸张外发光。

## 五、文字与字体

采用精致的日系幻想 RPG 排版风格。

中文文字必须清晰、正确、容易阅读。

英文标题使用优雅、简洁的衬线字体或高品质游戏标题字体。

数字采用统一的现代数字字体，保证货币数量、保底次数和抽卡价格具有良好的辨识度。

标题、说明文字、辅助信息之间必须有明确的字号和字重层级。

避免不必要的装饰字体和过度倾斜的文字。

## 六、装饰细节

允许少量使用星轨线条、星辰符号、精致银色边框、细线分隔和淡金色标记。

装饰必须服务于信息结构，不能为了华丽而堆叠元素。

当前选中卡池可以使用细致的群青色高亮标记。

UP 标识需要清楚醒目，但不要做成廉价促销标签。

保底进度使用简洁的进度条和数字，不要设计成复杂仪表盘。

## 七、严格禁止

不要重新生成抽卡背景。

不要改变角色立绘。

不要改变现有卡池内容。

不要重新安排整体布局。

不要增加无用的装饰面板。

不要满屏玻璃卡片。

不要过度使用描边。

不要使用大量发光边框。

不要添加无意义的星星、粒子和光环。

不要使用赛博朋克风格。

不要使用网页后台风格。

不要出现乱码、错误文字或虚构数据。

## 最终目标

让现有抽卡界面看起来像一款真正成熟的商业二次元 RPG 游戏。

界面干净、排版精致、信息清晰、层级明确、装饰克制。

角色立绘负责吸引玩家，背景负责营造氛围，UI 负责清晰地呈现信息。

三者互相配合，而不是互相争夺视觉焦点。

核心设计理念：

「让界面退后一步，让角色与星辰成为主角。」
