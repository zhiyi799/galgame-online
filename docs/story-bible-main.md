# ASTRAL BLOOM — 星樱物语 · 主线故事圣经

> 本文档为用户原文保存；起草时粘贴的外部参考图链接已略去。

我建议《ASTRAL BLOOM 星樱物语》的主线不要单纯做成传统的拯救世界故事，而是做成一部 **青春群像、星际幻想、文明探索、悬疑阴谋与悲剧史诗结合的长篇 RPG 故事**。

可以吸收几部作品各自擅长的部分：

- **《龙族》**：年轻人的成长、学院生活、神秘血统、宿命感、人物之间的羁绊，以及关键人物牺牲带来的情感冲击。
- **《明日方舟：终末地》**：未知地域探索、文明遗迹、工业与幻想结合、组织之间的利益冲突，以及世界背后的宏大谜团。
- **《鸣潮》**：灾变后的世界、特殊共鸣能力、古代文明、遗迹探索和逐步揭开的历史。
- **《棕色尘埃2》**：章节式冒险、鲜明的角色个性、人物关系、不同地区的独立故事，以及剧情和角色命运的紧密联系。

但世界观、人物、剧情和核心设定全部原创，不直接复刻这些作品。

下面我按照可以真正用于游戏开发的标准，为你设计一套主线框架。

# **ASTRAL BLOOM — 星樱物语**

## **主线故事：《星辰尽头，樱花未眠》**

# **序章：当群星坠落**

> 「如果有一天，天空中的星星全部熄灭，你还会记得自己曾经仰望过它们吗？」

很久以前，人类生活在一个被称为「星海」的世界。

天空中存在着无数星辰，每一颗星辰都对应着一个文明、一段记忆，甚至一个曾经真实存在过的生命。

人类将这种力量称为——星律。

星律不仅能够改变自然规律，还能让人类获得超越常理的能力。

然而，在距今约三百年前，一场被称为「寂星灾变」的灾难降临。

天空中的星辰开始接连熄灭。

大陆出现无法解释的空间裂隙，城市在一夜之间消失，部分人类发生异变，古代文明留下的遗迹开始重新活动。

人类将这些现象称为「失序」。

灾变之后，世界被分割成多个相互隔绝的区域。

幸存者建立了新的城市、研究机构和防卫组织。

人们逐渐忘记了灾变以前的历史。

但有一个问题始终无人能够解释：

为什么所有古代遗迹中，都出现了同一个符号？

一个五瓣花朵与星辰重叠的图案。

它的名字是——

**星樱。**

# **一、世界观设定**

## **1. 世界：艾斯特拉**

游戏发生在艾斯特拉大陆。

这里不是一个完全和平的幻想世界，而是一个经历过文明毁灭、正在重新建设的世界。

大陆主要分为五个区域。

| 区域    | 特征             | 剧情定位  |
| ----- | -------------- | ----- |
| 星环城   | 人类最大都市、学院、研究机构 | 主线起点  |
| 雾海边境  | 未知生物、失序区域      | 探索与冒险 |
| 白塔遗域  | 古代文明、星律研究      | 历史谜团  |
| 苍穹工业区 | 能源设施、机械都市      | 组织冲突  |
| 永夜之森  | 古老生命、星樱遗迹      | 世界真相  |

这些区域并不是单纯的地图。

每个地区都拥有自己的政治结构、文化、居民、历史和独立故事。

玩家会在探索中逐渐发现，它们之间存在着某种不应该存在的联系。

## **2. 核心力量体系：星律**

所有特殊能力都来自星律。

星律不是简单的魔法，而是世界运行规则的一部分。

不同的人能够感知不同类型的星律，并通过自身的精神、记忆和意志将其转化为力量。

主要分为六种属性：

| 属性 | 能力方向     | 特征    |
| -- | -------- | ----- |
| 星  | 空间、引力、星体 | 群青与银白 |
| 潮  | 波动、共鸣、流动 | 深蓝    |
| 炽  | 能量、燃烧、爆发 | 赤红    |
| 岚  | 风场、速度、切割 | 青绿    |
| 岩  | 防御、重构、稳定 | 金褐    |
| 幻  | 精神、记忆、认知 | 紫银    |

每个人的星律都不完全相同。

有人能够操纵重力，有人能够听见遗迹中的声音，也有人能够短暂改变周围的时间感知。

但星律使用过度，会产生一种副作用：

**记忆侵蚀。**

使用者越频繁地突破自身极限，就越可能失去某些记忆。

有的人忘记自己的名字，有的人忘记最重要的人，还有的人甚至忘记了自己为什么而战。

这将成为整个主线的重要情感机制。

# **二、主要组织**

## **1. 星环学院**

玩家主要活动场所

表面上是一所培养星律研究者、探索者和战斗人员的学院。

实际上，它是人类目前最重要的星律研究机构之一。

玩家会在这里认识主要角色，接受任务，参加训练，调查遗迹。

学院有着比较轻松的日常生活：

- 新学员入学。
- 社团活动。
- 课程与考试。
- 训练场对抗。
- 学院内部比赛。
- 夜间探索。
- 角色个人委托。

但学院并不完全安全。

有些教师知道灾变的真相，却选择保持沉默。

## **2. 星穹联合会**

由多个城市组成的联合组织。

负责探索失序区域、维护能源设施、保护人类聚居地。

他们希望通过星律技术重建文明。

但联合会内部存在不同派系。

有的人想保护普通人，有的人则认为牺牲少数人是必要代价。

## **3. 白昼议会**

一个掌握大量古代文明资料的神秘组织。

他们相信，寂星灾变并不是自然灾害。

他们一直在寻找一种被称为「初始星核」的东西。

他们知道某些真相，却不愿意让世界知道。

## **4. 无星者**

没有办法被正常星律仪器识别的人。

他们被视为异常个体。

有人认为他们没有星律天赋，也有人认为他们是灾变留下的错误。

而玩家将发现：

无星者并不是没有星律。

而是他们的星律不属于这个时代。

# **三、主角设定**

## **玩家：无星者**

玩家并非传统意义上的天选之子。

故事开始时，玩家只是一个普通的年轻人。

在一次星环城外围的遗迹调查中，玩家意外遭遇空间崩塌。

同行人员全部失联。

玩家却在废墟深处看见了一颗不应该存在的星辰。

那颗星辰进入了玩家体内。

此后，玩家获得了一种奇怪的能力：

**能够听见已经消失的星辰留下的声音。**

但每当玩家使用这种力量，就会看到一些不属于自己的记忆。

陌生的城市、陌生的人、陌生的战争。

甚至还有一个声音不断呼唤玩家：

「这一次，你终于回来了吗？」

主角的核心谜团：

- 为什么能够听见已经消失的星辰？
- 为什么古代遗迹会对主角产生反应？
- 为什么主角的档案在三百年前就已经存在？
- 为什么有人坚称自己曾经见过主角？

# **四、核心女主角**

## **塞蕾斯蒂娅 · Celestia**

五星限定角色 · 核心剧情人物

**身份：星轨观测局首席观测者**

**属性：星**

**定位：星核操纵者**

**性格：** 安静、理性、温柔，对陌生人保持距离。

她是星环学院最神秘的研究人员之一。

拥有极高的星律适应能力，能够直接观测星辰的运行轨迹。

她腰间的装置被称为「星核稳定器」。

手中悬浮的蓝色星体则是她一直守护的特殊星核。

她从不谈论自己的过去。

因为她已经忘记了自己曾经最重要的一个人。

第一次与主角见面时，她看着主角体内的星律，表现出了罕见的失态。

她说：

「不可能……这颗星辰，明明已经消失了。」

随着剧情推进，玩家会发现她并不是单纯的星律研究者。

她曾经参与过三百年前的某项实验。

而她真正的年龄，也远远超过所有人的想象。

她守护的并不是一颗星球。

而是一段被整个世界遗忘的历史。

# **五、主线剧情：第一部《失序的星环》**

第一部预计分为八章。

每一章都有一个独立事件，同时推进世界真相。

## **第一章：无星者**

玩家进入星环城。

因为没有星律检测结果，主角无法正常通过学院的入学评估。

一次意外的遗迹事故，让主角展现出异常能力。

学院将主角列入特殊观察名单。

塞蕾斯蒂娅第一次出现。

她看着主角，问了一个奇怪的问题：

「你有没有在梦里，见过一片没有星星的天空？」

章节结尾：

主角收到一份三百年前的档案。

档案中的照片，竟然与现在的自己一模一样。

## **第二章：学院的夜晚**

主角正式开始学院生活。

这一章强调人物群像。

玩家会认识第一批主要伙伴：

- 活泼开朗、擅长近战的少女。
- 性格冷淡、拥有贵族背景的学生。
- 对古代机械充满兴趣的技术天才。
- 看似普通、却总能提前预测危险的少年。

这一章前半段以学院日常、训练和角色互动为主。

后半段，一场学院内部的模拟测试发生异常。

原本只是训练用的古代遗迹突然启动。

一名学生在所有人面前消失。

更奇怪的是，其他人开始逐渐忘记这个学生的存在。

只有主角还记得他。

章节结尾：

主角在学院档案室发现了一份名单。

名单上所有人的名字，后面都标注着同一个词：

「已被星辰删除」。

## **第三章：雾海列车**

学院派遣主角小队前往雾海边境。

途中，他们乘坐一列已经运行了几十年的古代列车。

列车上有商人、佣兵、研究人员和普通居民。

玩家在这里第一次感受到灾变后世界的真实生活。

但列车进入雾海深处后，所有车厢开始出现时间异常。

乘客不断看见已经死去的亲人。

列车广播开始播放一段三百年前的求救信号。

最终，小队发现整列列车正行驶在一段已经从现实中消失的铁路上。

而列车终点站的名字是：

「星环城」。

但那是一座三百年前的星环城。

章节结尾：

主角在列车的最后一节车厢中，发现了一个与自己长得完全一样的人。

## **第四章：白塔之下**

小队进入白塔遗域。

这里保存着大量灾变以前的历史资料。

他们发现，古代人类早已掌握星律技术。

而且曾经成功预测过寂星灾变。

但在灾变发生前，所有预测资料被人为删除。

塞蕾斯蒂娅在遗迹中出现异常。

她开始看见一些只有自己才能看见的记忆。

她想起自己曾经站在一座巨大的观测塔上。

天空中有无数星辰。

身旁有一个看不清面容的人。

那个人对她说：

「如果世界真的走到尽头，你就替我记住它。」

章节结尾：

白塔启动。

所有墙壁同时显示出一行文字：

「星樱计划，执行失败。」

## **第五章：苍穹之城**

小队来到苍穹工业区。

这里与星环城完全不同。

机械设施、能源管线、工业平台构成了巨大的城市。

当地居民依靠星核能源生活。

然而，联合会正在秘密进行一项实验：

将失序区域中的生命作为星律能源来源。

玩家发现，这项实验已经造成大量人员伤亡。

而实验负责人坚信：

如果不这么做，人类文明将在几十年内彻底灭亡。

这一章不设置单纯的邪恶反派。

玩家必须面对一个问题：

当整个世界即将毁灭时，牺牲一部分人是否合理？

章节结尾：

主角发现，塞蕾斯蒂娅曾经签署过同一项实验的初始文件。

## **第六章：没有名字的人**

这一章是第一部最重要的情感章节。

主角的一名伙伴在一次任务中受到严重的星律侵蚀。

他的记忆开始不断消失。

最初，他忘记任务内容。

后来，他忘记自己的朋友。

最后，他甚至忘记了自己的名字。

但即便如此，他依然记得一件事：

自己必须保护主角。

在最终战斗中，他选择将最后的星律全部交给主角。

他留下的最后一句话是：

「如果以后你还能记得我……就替我看看真正的星空吧。」

战斗结束后，所有记录中都不再存在他的名字。

只有主角的记忆里，依然保留着他的身影。

这让玩家第一次真正理解：

星律的代价不是死亡。

而是被整个世界遗忘。

## **第七章：永夜之森**

主角一行进入永夜之森。

这里有着整片大陆最古老的生命。

所有植物都能够感知星律。

树木中保存着无数人的记忆。

小队终于找到星樱遗迹。

他们发现：

星樱并不是一种植物。

而是一套古代文明用于保存生命记忆的系统。

三百年前，人类发现世界正在逐渐失去星律。

为了阻止文明彻底毁灭，古代研究者启动了星樱计划。

他们试图将整个文明的记忆保存起来。

但实验发生了无法控制的错误。

世界开始不断重复同一段历史。

每一次循环，都有人被遗忘。

每一次循环，都有文明消失。

而塞蕾斯蒂娅，就是上一轮历史中留下来的人。

## **第八章：星辰尽头**

白昼议会终于现身。

他们宣布启动「最终观测」。

真正的目的不是拯救世界。

而是终止所有不稳定的生命记忆，让世界回归最初的状态。

他们认为：

只要消除所有不确定性，就能创造一个永远不会毁灭的世界。

塞蕾斯蒂娅决定阻止他们。

但她知道，自己的星核已经无法继续稳定。

如果强行使用全部力量，她将失去所有记忆。

包括她与主角之间的所有经历。

最终战斗中，主角与塞蕾斯蒂娅共同进入星樱系统。

在系统最深处，主角看到了一个惊人的事实：

**所谓的寂星灾变，并不是世界毁灭的开始。**

而是世界已经毁灭过无数次之后，留下的最后一次机会。

最后，塞蕾斯蒂娅看向主角。

她问：

「如果有一天，我再也不记得你了……」

「你还会重新认识我吗？」

第一部结束。

第一部完结

# **六、真正的长期主线：三部曲结构**

我不建议八章之后就把世界真相全部揭开。

这个项目更适合做成长篇连续剧情，每一部解决一个谜团，同时产生更大的问题。

**第一部：失序的星环**

主题：相遇、成长、记忆

玩家认识伙伴，进入星环学院，调查失序事件，发现星樱计划。

**第二部：苍穹之外**

主题：文明、选择、牺牲

玩家前往大陆以外的未知区域，发现其他文明也曾经历相同的循环。不同组织开始争夺星核，主角逐渐发现自己与初始星核之间的关系。

**第三部：星樱的终焉**

主题：命运、自由、再会

玩家进入星樱系统的源头，揭开世界循环的真正原因，决定是否保留一个并不完美、却真实存在的世界。

# **七、我建议加入的几个重要设计**

这部分决定游戏能不能有类似长篇动漫和大型 RPG 的吸引力。

## **1. 不要让所有角色只围绕主角转**

每个重要角色都应该有自己的目标、秘密和立场。

例如：

- 有人想找到失踪的家人。
- 有人想证明自己的家族没有参与灾变。
- 有人想摧毁星律研究机构。
- 有人想成为联合会最高负责人。
- 有人知道自己即将被星律侵蚀，却假装什么都没发生。

甚至可以让原本关系很好的伙伴，在不同事件中产生真正的理念冲突。

## **2. 每个章节都要有独立的故事**

不要八章全部围绕寻找遗迹。

可以采用不同题材：

| 章节类型 | 剧情方向         |
| ---- | ------------ |
| 学院篇  | 青春、友情、成长     |
| 调查篇  | 悬疑、推理、失踪事件   |
| 列车篇  | 封闭空间、群像、时间异常 |
| 遗迹篇  | 古代文明、历史真相    |
| 工业篇  | 阶级冲突、组织斗争    |
| 悲剧篇  | 牺牲、记忆、人物命运   |
| 探索篇  | 未知地域、古老生命    |
| 终章   | 世界真相、最终抉择    |

## **3. 抽卡角色必须进入主线**

这一点对你的游戏尤其重要。

我不建议让抽卡角色只是战斗单位。

每个五星角色都应该有：

- 正式主线登场。
- 独立人物关系。
- 个人背景故事。
- 角色专属章节。
- 专属剧情演出。
- 与主线世界观相关的秘密。

玩家抽到角色后，还可以解锁角色档案、语音、回忆和个人故事。

这样抽卡就不只是获取战斗数值，也是认识角色、了解世界的过程。

# **八、最重要的：第一部的开场演出**

# **ASTRAL BLOOM — 星樱物语**

## **核心主线三大叙事支柱**

整部《星樱物语》围绕三个问题展开：世界为什么走到了今天？我们究竟因为什么相遇？如果终有一天彼此遗忘，那么曾经建立的羁绊又是否真实存在？

这三个问题将贯穿整个游戏的主线、角色故事、章节剧情和最终结局。

# **第一条：世界之谜——被遗忘的三百年**

**核心问题：三百年前究竟发生了什么？星樱计划为什么会失败？世界为什么不断重复？**

三百年前，艾斯特拉并不是如今这个支离破碎的世界。

那时的文明已经掌握了成熟的星律技术。人类能够观测遥远星辰，利用星核建立城市，甚至尝试干涉空间、时间与生命的运行规律。

星辰不再只是天空中的光点。

它们是文明的记录者，是生命的见证者，也是整个世界维持稳定的重要组成部分。

然而，古代观测者发现了一个无法解释的现象：

**星辰正在逐渐失去光芒，而这一过程无法逆转。**

起初，人们认为这只是星律周期性衰退。

直到某一天，第一座城市从世界上彻底消失。

没有爆炸，没有战争，也没有任何灾难发生的痕迹。

城市中的数十万人，就像从未存在过一样。

他们的亲人忘记了他们，历史档案失去了他们，甚至连他们曾经生活过的街道也发生了变化。

这场灾难被称为「寂星灾变」。

为了阻止世界继续消失，古代文明启动了一个规模空前的计划：

**星樱计划。**

星樱计划的目标，是利用初始星核建立一个能够保存整个文明记忆的系统。

他们希望即使世界崩塌，文明也能通过记忆重新建立。

但实验最终失败。

星樱系统失去了控制，世界开始出现无法解释的重复现象。

已经毁灭的城市重新出现，死去的人再次生活，历史被反复改写。

然而，每一次重新开始，都会有一些东西永远消失。

有人失去了姓名，有人失去了过去，有人失去了自己最重要的人。

而世界似乎正在不断缩小。

### **三百年前的真正秘密**

随着剧情推进，玩家会逐渐发现：

寂星灾变并不是一场普通的自然灾害。

星樱计划也并非单纯为了保存文明。

古代研究者早已发现，世界本身正在走向某种不可逆转的终结。

他们试图通过保存记忆，让文明在世界毁灭之后继续存在。

但他们犯下了一个致命错误：

他们试图保存所有人的记忆，却没有考虑到一个问题。

**如果记忆能够被保存，那么被记忆保存的人，究竟还是不是原本的那个人？**

星樱系统开始不断重建世界。

但重建出来的世界并不完全真实。

它只是根据残留记忆拼接而成的结果。

每一次循环，都有一些无法被完整保存的生命被逐渐抹去。

而玩家所生活的世界，可能已经不是最初的世界。

### **第一条主线最终要回答的问题**

- 寂星灾变究竟是自然现象，还是某种人为干预的结果？
- 星樱计划究竟想拯救文明，还是试图制造一个永恒不变的世界？
- 为什么世界会不断重复？
- 初始星核究竟保存着什么？
- 如果现在的世界只是记忆重建的结果，那么它还有没有继续存在的价值？

最终，玩家需要面对一个选择：

是让世界继续维持循环，保留现有的一切，还是结束星樱系统，让这个世界真正迎来未知的未来？

# **第二条：人物命运——被星辰选中的人**

**核心问题：塞蕾斯蒂娅为什么一直守护星核？主角究竟是谁？伙伴们又为什么会被卷入这场灾难？**

《星樱物语》不应该让角色只是陪伴主角完成任务的工具。

每个人都应该拥有自己的过去、目标、遗憾和选择。

他们因为不同的原因来到主角身边，也会因为不同的理由走向各自的命运。

## **1. 塞蕾斯蒂娅：被遗忘的守望者**

她是整个故事中最重要的角色之一。

三百年前，她曾经参与星樱计划。

她并不是计划的创造者，也不是单纯的执行者。

她曾经拥有自己的生活、朋友，以及一个非常重要的人。

星樱计划失败之后，她成为了少数没有被系统完全重建的人。

她失去了大量记忆，却保留了对星核的守护本能。

她不知道自己究竟等待了多久。

也不知道自己为什么不能放弃那颗蓝色星核。

她只记得，在一切结束之前，有人曾经对她说过：

「无论发生什么，都不要让这颗星辰熄灭。」

于是，她一直守护着星核。

三百年过去，她见过无数城市兴衰，见过无数人出生、成长、死亡。

她也曾经尝试与别人建立关系。

但每当世界再次循环，那些人就会消失。

只有她还记得。

或者说，她还残留着一些无法解释的记忆。

直到主角出现。

她第一次在一个陌生人身上，感受到三百年前熟悉的星律。

她开始怀疑：

自己一直等待的人，终于回来了。

但她也害怕。

因为如果主角真的是那个人，那么这一次，她可能又要亲眼看着对方消失。

**她守护星核，是因为她已经忘记了那个人是谁，却始终没有忘记自己答应过什么。**

## **2. 主角：不存在于历史中的人**

主角最初只是一个普通的年轻人。

没有显赫的家族，没有特殊的身份，也没有被任何组织认可的能力。

但在一次遗迹事故中，主角获得了能够听见消失星辰声音的能力。

随着调查深入，玩家逐渐发现：

三百年前的古代档案中，竟然存在主角的资料。

不仅如此，某些已经消失的城市中，也存在与主角有关的记录。

有人称主角为救世者。

有人称主角为灾变的源头。

还有人看见主角时，会露出仿佛等待了很久的表情。

但主角自己什么都不记得。

随着剧情推进，玩家会发现主角与星樱计划存在极深的联系。

主角可能是星樱系统中一个无法被完整删除的变量。

也是整个循环中，唯一能够真正改变结果的存在。

但主角究竟是三百年前某个人的延续，还是星樱系统创造出来的新生命？

这个问题不能太早揭晓。

因为它最终关系到整个故事的主题：

**一个人的价值，究竟来自他的过去，还是来自他现在所做出的选择？**

## **3. 伙伴们：每个人都有自己的星空**

主角的伙伴不应该只是为了推动主线而存在。

每个人都应该有属于自己的故事。

有人因为失去亲人而加入学院，有人为了证明家族的清白而调查灾变，有人希望利用星律技术拯救自己的故乡，也有人只是想过上普通的生活。

他们可能会争吵，会怀疑彼此，会做出错误的决定。

有些人甚至会在某个章节与主角站在对立面。

但正是这些不同的选择，让他们成为真正独立的人物。

随着主线推进，玩家会发现：

这些伙伴并不是偶然聚集在主角身边的。

他们每个人都与三百年前的某个事件存在联系。

他们的家族、能力、记忆，甚至出生的地方，都可能是星樱计划留下的痕迹。

然而，他们并不是命运安排好的棋子。

他们可以拒绝自己的过去，也可以选择一条与历史完全不同的道路。

### **第二条主线最终要回答的问题**

- 塞蕾斯蒂娅等待了三百年，究竟在等待谁？
- 主角与三百年前的自己究竟是什么关系？
- 伙伴们为什么会被卷入星樱计划？
- 如果一个人的记忆被彻底改变，他还是原来的那个人吗？
- 如果命运早已写好，人是否仍然拥有选择的自由？

最终，玩家会发现：

真正决定人物命运的，不是他们来自哪里，而是他们愿意为了什么继续前进。

# **第三条：情感主题——即使遗忘，也曾真实相遇**

**核心问题：如果记忆会消失，如果重要的人终究会离开，那么人与人之间建立的羁绊还有意义吗？**

这是《星樱物语》最重要的一条主线。

世界之谜可以让玩家感到震撼，人物命运可以让玩家产生共鸣。

但真正让玩家记住这部作品的，应该是那些曾经一起经历过的事情。

学院里的一次普通晚餐。

任务结束后的一场争吵。

深夜训练场里的一次陪伴。

某个人明明害怕，却依然选择站在同伴面前。

这些事情看起来并不伟大。

但它们可能是角色一生中最珍贵的回忆。

## **1. 记忆不是羁绊的全部**

星律侵蚀会让人失去记忆。

一个人可能忘记朋友的名字，忘记曾经一起经历的事情，甚至忘记自己为什么会爱上另一个人。

但这并不意味着所有感情都会立刻消失。

有些人即使忘记了对方，也会下意识地为对方留出位置。

有些人即使不记得曾经发生过什么，仍然会在危险来临时选择保护对方。

有些人甚至不知道自己为什么会流泪。

因为记忆消失了。

但曾经发生过的事情，并不会因此变成虚假。

## **2. 不要让所有离别都变成牺牲**

故事中的悲剧不应该只有死亡。

有些离别比死亡更加残酷。

例如：

一个伙伴成功活了下来，却忘记了曾经最好的朋友。

一个角色终于回到了故乡，却发现所有人都不记得自己。

两个人明明重新相遇，却因为记忆被改变，再也无法像过去一样相处。

还有一种更加残酷的情况：

一个人记得所有事情，却发现自己已经成为唯一记得过去的人。

这些情节可以成为角色个人故事的重要内容。

但并不是所有角色都必须走向悲剧。

有些人可以重新找到生活的意义，有些人可以原谅过去，有些人可以在失去之后重新建立关系。

这样，悲剧才会有真正的重量。

## **3. 塞蕾斯蒂娅与主角的羁绊**

塞蕾斯蒂娅是这条情感主线最重要的承载者。

她一直守护着星核。

她知道自己可能会再次失去记忆。

也知道主角可能会再次离开。

但她仍然选择与主角同行。

因为她逐渐明白：

自己守护的并不是一段永远无法改变的过去。

而是未来仍然有可能发生的相遇。

在故事的某个重要节点，主角可能会发现：

塞蕾斯蒂娅已经不记得两人曾经经历过的许多事情。

她忘记了第一次相遇。

忘记了共同完成的任务。

忘记了那些在夜晚说过的话。

但当主角再次向她伸出手时，她仍然愿意握住。

她可能会问：

「我们以前……是不是在哪里见过？」

主角回答：

「也许吧。」

「不过没关系。」

「我们可以重新认识一次。」

## **4. 最终的情感命题**

在故事的最后，玩家将面对星樱系统。

它能够保存所有人的记忆。

也能够让已经失去的人重新出现在世界上。

但代价是：

所有人的未来都将被固定。

世界不会再发生无法预测的变化。

不会再有意外。

不会再有失去。

但也不会再有真正意义上的选择。

星樱系统认为，这样的世界才是完美的。

因为所有人都能永远留在自己最幸福的记忆中。

但主角逐渐明白：

**如果为了不再失去而放弃未来，那么所谓的永恒，也只不过是一座没有出口的牢笼。**

人会相遇，也会离别。

会记住，也会遗忘。

会犯错，也会后悔。

但正因为无法永远拥有，才更应该珍惜那些真实发生过的瞬间。

最终，主角选择让世界继续向前。

不是因为他不害怕失去。

而是因为他不愿意让所有人都失去选择未来的权利。

# **十、三条主线的最终交汇**

在最终章节，三条主线将汇聚在一起。

**世界之谜：**

星樱系统为什么不断重建世界？

因为它始终无法接受文明的彻底消失。

**人物命运：**

塞蕾斯蒂娅为什么守护星核？

因为她曾经答应过一个人，要让星辰继续存在。

主角究竟是谁？

他是过去留下的谜题，也是未来可以做出新选择的人。

**情感主题：**

羁绊是否有意义？

即使记忆消失，即使无法再次相认，曾经真实存在过的感情依然有意义。

最终，星樱系统向主角提出最后一个问题：

「如果你知道未来一定会失去他们，为什么还要让这一切继续？」

主角没有立即回答。

他看向身边的伙伴。

有人已经不记得自己的过去。

有人失去了最重要的人。

有人仍然在害怕未来。

但他们依然站在这里。

于是主角回答：

「因为我们曾经一起走到这里。」

「因为即使有一天我们会忘记彼此，也不能否定我们曾经相遇。」

「我不需要一个永远不会失去任何人的世界。」

「我只希望，他们能够拥有选择自己未来的权利。」

星樱系统停止运转。

天空中，沉寂了三百年的星辰开始重新闪烁。

那些曾经被遗忘的城市，没有全部回来。

那些已经离开的人，也没有全部复活。

但世界终于不再重复同一段历史。

它开始向一个未知的未来前进。

塞蕾斯蒂娅站在主角身旁。

她看着天空，沉默了很久。

随后轻声问道：

「我们以后……还会再见面吗？」

主角回答：

「当然。」

「这一次，我们不用再等待三百年了。」

# **十一、贯穿整个游戏的核心台词**

这些台词可以作为不同章节的主题句，在主线、角色 PV、登录界面、章节结尾和宣传片中反复出现。

**关于世界：**

「星辰熄灭之后，世界依然会继续运转。只是再也没有人记得，它曾经有多么明亮。」

**关于命运：**

「如果我们的相遇早已被写进过去，那么这一次，我想亲自决定自己的未来。」

**关于记忆：**

「忘记一个人，并不意味着那个人从未存在过。」

**关于离别：**

「我并不害怕你离开。我害怕的是，有一天连我也忘记了你曾经来过。」

**关于塞蕾斯蒂娅：**

「我已经忘记了等待的理由。但只要星辰还没有熄灭，我就会继续等下去。」

**关于主角：**

「我不知道自己从哪里来，但我知道，这一次，我想和大家一起走向未来。」

**关于最终结局：**

「即使整个世界都忘记了你，我也会记得，我们曾经一起看过星空。」

# **十二、作品最终想表达的东西**

《ASTRAL BLOOM 星樱物语》不应该只是一部关于星辰、灾变、遗迹和力量的幻想故事。

它真正想讲述的是：

一个不断重复历史的世界，一群背负着不同命运的年轻人，以及他们在漫长旅途中建立起来的羁绊。

他们会经历相遇、争吵、成长、离别与重逢。

他们会发现自己并不特殊，也无法拯救所有人。

但他们依然能够做出自己的选择。

世界不一定会因为他们而变得完美。

但至少，他们可以让这个世界拥有继续前进的可能。

**最终主题：**

# **星の彼方、桜の約束**

## **星辰的彼方，樱花的约定**

# **「即使终有一天，我们会忘记彼此。」**

# **「至少此刻，我们真实地相遇过。」**

ASTRAL BLOOM — 星樱物语

这就是三条主线最终应该共同指向的答案：

**世界的意义，不在于永远不变；人物的意义，不在于永远不被遗忘；而羁绊的意义，在于即使知道终有一天会失去，仍然愿意认真地与彼此相遇。**

## 第一章执行定案（用户 2026-11-17 定案）

以下为第一章剧本四处待定点的最终决定，与剧本 `story-chapter-01-script.md` 末尾的定案一致。

| 项目 | 最终决定 |
| --- | --- |
| 两次遗迹事故 | 背景事故发生在故事开始前约三个月，灰塔事故发生于第一章 |
| 两次事故关系 | 独立事件，但都与同一古代实验及主角星律印记有关：背景事故留下印记，灰塔事故真正唤醒它 |
| NPC 名字 | 罗恩、艾格尼丝、加雷斯、布兰特全部保留 |
| 遗迹名称 | 灰塔遗迹，保留 |
| 档案送达方式 | 无寄件人的档案袋出现在主角宿舍门口；封口处有一枚已经模糊的五瓣星樱标记；最后一页手写「如果你已经开始听见星辰的声音，就不要再相信所有人都记得同一段历史。」；来源本章不揭示，后续与白昼议会、塞蕾斯蒂娅以及星樱计划联系 |
| 主角性别与外貌 | 双性别预设主角：男/女两版预设形象，玩家选择；剧情、人物关系、核心台词不因性别改变；剧本文字不固定发色、瞳色、身高或服装；统一星律印记与关键演出；重要过场用第一人称镜头、背影、手部特写和局部面部表现 |

**创作原则：** 这些决定是剧本执行层面的定案，不代表要提前揭开世界谜团。尤其是两次遗迹事故、档案来源和主角真实身份，应该让玩家先感受到异常，再通过章节推进逐步理解。

**第一章悬疑链条：** 梦境 → 灰塔事故 → 神秘档案 → 三百年前的主角照片。
