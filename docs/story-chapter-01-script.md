## 章节目标总览

本章要向玩家交代清楚四件事：

1. 主角是谁——一个测不出星律的「无星者」，刚刚抵达星环城。
2. 主角身上有什么异常——体内有一颗不应该存在的星辰，能听见消失的星辰的声音。
3. 谁注意到了主角——星环学院将主角列入特别观察名单；塞蕾斯蒂娅第一次正式出现。
4. 本章最大的悬念——一份三百年前的档案，照片上的人与主角一模一样。

## 场景 0：序幕演出 ——「没有星星的天空」

**类型：** 纯演出（不可操作），约 2 分钟。
**演出注：** 本段为梦境 / 记忆碎片，呈现的是故事开始前约三个月的背景遗迹事故——主角在星环城外围遗迹调查中遭遇空间异常，只记得破碎的星空、失真的钟声、一个似乎认识自己的声音，不立即交代完整经过。主角醒来后记不清少女的面容与对话细节，第一章中与塞蕾斯蒂娅的相遇仍为「第一次」正式见面。背景事故在主角身上留下了星律印记（手掌蓝色星纹）；第一章的灰塔事故将真正唤醒它。两次事故的联系逐步揭晓，不要太早解释。画面风格参考圣经第八节「第一部的开场演出」。

**分镜：**

1. [黑场] 很轻的女声。
2. [音效] 远处传来钟声。
3. [画面] 天空中，一颗星辰熄灭。
4. [镜头切换] 一座被遗弃的城市。一列停在月台上的列车。一片无人记得的樱花树。
5. [画面] 年轻的主角在废墟中醒来，手掌上出现一枚蓝色星纹。
6. [画面] 远处出现一个陌生少女，银灰色长发在夜风中轻轻摆动，手中悬浮着一颗蓝色星体。少女缓缓抬起头。
7. [画面骤然变黑] 标题：ASTRAL BLOOM / 星樱物语 / 星の彼方、桜の約束。

**对白：**

- 女声（轻）：「你相信星星会记得一个人吗？」
- 少女：「……终于找到你了。」
- 主角：「我们认识吗？」
- 少女（沉默了很久，露出很淡的笑容）：「以前认识。」
- 少女：「只是你已经不记得了。」

**转场：** 黑场淡出 → 场景 1。主角从梦中惊醒。

## 场景 1：星环城·南门 ——「抵达」

**地点：** 星环城·南门（城门检查站，主街入口）。
**出场人物：** 主角、城门守卫布兰特、同期考生罗恩。
**演出注：** 白天。星环城是人类最大都市，远景可见学院高塔与星环状的环城建筑。主角刚从梦中惊醒，站在入城队伍里。

**对白：**

- 主角（心声）：（又是那个梦……没有星星的天空，还有那个看不清脸的少女。）
- 布兰特：「站住。通行证。」
- 主角：「……给。」
- 布兰特：「外地来的？今天学院评估，来考试的？」
- 主角：「嗯。星环学院的入学评估。」
- 布兰特：「去吧。沿着主街一直走，看到最高的塔就是学院。提醒你一句——评估大厅门口那台检测仪，可不会对谁客气。」
- 罗恩：「嘿！你也是去学院的吧？」（小跑过来）
- 罗恩：「我叫罗恩，今年第三次来考了。你呢？第一次？」
- 主角：「……算是。」
- 罗恩：「别紧张。检测就是站上去，机器亮一下，告诉你是什么属性。星、潮、炽、岚、岩、幻——六种，总有一种是你的。」
- 主角（心声）：（可是……我从来没有感觉到过什么「星律」。从小到大，一次也没有。）
- 罗恩：「走吧，一起去。万一咱俩分到一个班，还能互相照应。」

**互动：**
- 与布兰特交谈（可选）：打听星环城与学院的基本情况。
- 与罗恩同行，沿主街前往学院（引导路线，沿途可查看两处场景说明：星环纪念碑、学院招生告示）。

**任务更新：** 1-1 完成 → 1-2 进行中。
**转场：** 主街淡入 → 场景 2。

## 场景 2：星环学院·评估大厅 ——「没有结果的检测」

**地点：** 星环学院·评估大厅（星律检测仪前）。
**出场人物：** 主角、罗恩、评估官艾格尼丝、若干同期考生（背景）。
**演出注：** 大厅明亮，人声嘈杂。检测仪是一台环形装置，站上去后会扫描全身并在屏幕上显示属性。主角之前从未接受过正式检测。

**对白：**

- 艾格尼丝：「下一个。姓名。」
- 主角：「……（玩家）。」
- 艾格尼丝：「站到检测台上，放松，不要抵抗。」
- [演出] 检测仪亮起，扫过主角，全场安静。仪器屏幕：一片空白。
- 艾格尼丝：「……再测一次。」
- [演出] 检测仪再次扫过，依然空白。周围考生低声议论。
- 考生甲（小声）：「什么都没有？那是……无星者？」
- 考生乙（小声）：「仪器测不出来的人，一百年也没几个吧。」
- 罗恩（小声）：「别慌，也许是机器坏了……」
- 艾格尼丝：「检测结果：无。按章程，你无法通过正常入学评估。」
- 主角：「……就没有别的办法吗？」
- 艾格尼丝：「有一个。无法检测者，可以接受野外复核——随调查队前往城外遗迹，由队长现场评估你的实战反应。今天下午就有一支队伍出发。你去，还是不去？」

**对话选项（双选项收束，不分歧主线）：**

- 选项 A「去。」→ 艾格尼丝：「那就去报到。调查队在学院东门集合，队长加雷斯。」
- 选项 B「……让我想想。」→ 艾格尼丝：「没有时间给你想。去，或者回家——你自己选。」→ 主角：「……我去。」→ 艾格尼丝：「那就去报到。调查队在学院东门集合，队长加雷斯。」

**对白（续）：**

- 艾格尼丝：「记住——遗迹里没有第二次机会。跟紧队伍，别乱碰东西。」
- 罗恩：「喂，等等我！我也去！我也报野外复核！」
- 艾格尼丝：「……随你。东门集合，别迟到。」

**任务更新：** 1-3 完成（结果：未通过）→ 1-4 进行中。
**转场：** 大厅淡出 → 场景 3。

## 场景 3：星环城外围·灰塔遗迹 ——「崩塌」

**地点：** 星环城外围·灰塔遗迹（灾变前的观测站残骸）。
**出场人物：** 主角、罗恩、调查队队长加雷斯。
**演出注：** 下午。遗迹外围尚且平静，内部残破。调查开始后地面震动，出现空间裂隙，失序体涌出。本场为第一章唯一的战斗节点，同时也是主角能力第一次在人前显现。

**对白（调查阶段）：**

- 加雷斯：「都听好。灰塔遗迹是灾变前的观测站残骸，里面还有没搞清楚的机关。跟紧我，别乱碰东西。」
- 罗恩：「队长，听说这里以前能直接看到星星……」
- 加雷斯：「那是三百年前的事了。现在这里只有石头和失序反应。走。」
- 主角（调查观测台残件）：「这个符号……五瓣花，和星星重叠。在哪见过？」
- 罗恩：「到处都是这个符号，学院里、遗迹里，好像所有古代地方都有。你不知道？」
- 主角（心声）：（不是不知道……是觉得眼熟。像是在梦里见过很多次。）

**对白（崩塌与战斗）：**

- [演出] 地面剧烈震动，墙壁裂开，空间裂隙在半空张开，失序体从裂隙中涌出。
- 加雷斯：「空间崩塌！所有人后退——罗恩，左边！」
- 罗恩：「队、队长！数量太多了！」
- 加雷斯：「别慌！结阵——主角，你退到我身后去！」
- [战斗节点 1：教学战斗] 敌人：失序体 ×3。教学内容：普通攻击、移动、防御。主角此时没有正式星律技能，以基础攻击参战。战斗进行到失序体数量削减过半时，触发剧情。
- [演出] 一只失序体绕过加雷斯，扑向罗恩。主角下意识伸手——
- [演出] 主角手掌上的蓝色星纹亮起。世界安静了一瞬。
- 消失的星辰之声：「这一次，你终于回来了吗？」
- [演出] 主角眼前闪过不属于自己的记忆：一座星空下的城市，一座高耸的观测塔，一个看不清面容的人影。
- 主角（心声）：（这不是我的记忆……我从来没有来过这里。）
- [演出] 蓝光扩散，裂隙稳定下来，剩余失序体化作星尘消散。

**对白（事后）：**

- 罗恩：「……你、你刚才做了什么？那道光——」
- 加雷斯：「收队。立刻回学院。这件事，必须马上上报。」
- 主角：「罗恩，你没事吧……等等，你叫什么来着？」
- 罗恩：「……啊？我是罗恩啊。我们早上才在南门见过。」
- 主角：「……对不起。我刚才，好像有一瞬间想不起来了。」
- 加雷斯（盯着主角的手掌）：「你的手……刚才那个星纹，之前就有吗？」
- 主角：「……我不知道。从那次遗迹调查之后，它就一直在。」

**演出注（记忆侵蚀·机制预告）：**
- 主角使用能力后短暂忘记了罗恩的名字，随即恢复。这是「记忆侵蚀」在本作中的第一次表现：代价轻微，但真实存在。后续章节中侵蚀将逐步加重。
- 主角提到的「那次遗迹调查」指故事开始前约三个月的背景遗迹事故：星环城外围遗迹调查中遭遇空间异常，主角在废墟深处看见一颗不应该存在的星辰并被其进入体内，身上留下星律印记（手掌蓝色星纹）。本章的灰塔事故是另一次独立事件，但两者都是同一场古代实验留下的前后呼应——背景事故留下印记，灰塔事故真正唤醒它。本章不展开背景事故全貌，只以梦境与台词留白；两次事故的联系逐步揭晓，不要太早解释。

**任务更新：** 1-5 完成 → 1-6 进行中。
**转场：** 遗迹淡出 → 场景 4。

## 场景 4：星环学院·观察室 ——「塞蕾斯蒂娅」

**地点：** 星环学院·观察室（无窗，安静，墙上挂着星图）。
**出场人物：** 主角、评估官艾格尼丝、塞蕾斯蒂娅（第一次正式登场）。
**演出注：** 夜。塞蕾斯蒂娅已在室内等候。她腰间佩戴「星核稳定器」，手中悬浮着一颗蓝色星体。性格：安静、理性、温柔，对陌生人保持距离。

**对白：**

- 艾格尼丝：「就是他。遗迹里的空间崩塌，是他一个人稳定下来的。仪器至今测不出他的星律。」
- 塞蕾斯蒂娅：「……我知道了。你先出去吧。」
- 艾格尼丝：「观测者，这人——」
- 塞蕾斯蒂娅：「出去。」
- [演出] 艾格尼丝离开。房间里只剩主角和塞蕾斯蒂娅。她走到主角面前，仔细看着他。
- 塞蕾斯蒂娅：「把手伸出来。」
- 主角：「……」
- 塞蕾斯蒂娅：「手掌。让我看看。」
- [演出] 主角伸出手。掌心的蓝色星纹微微发光。她腰间的星核稳定器随之震动，手中悬浮的蓝色星体轻轻颤抖。
- 塞蕾斯蒂娅（罕见地失态）：「不可能……这颗星辰，明明已经消失了。」
- 主角：「……你说什么？」
- 塞蕾斯蒂娅（恢复平静）：「没什么。告诉我——你有没有在梦里，见过一片没有星星的天空？」
- 主角：「……有。经常做那个梦。天上什么都没有，只有我一个人站着。」
- 塞蕾斯蒂娅：「……果然。」
- 主角：「你到底是谁？你知道我身上发生了什么，对不对？」
- 塞蕾斯蒂娅：「我是塞蕾斯蒂娅，星轨观测局首席观测者。从今天起，你是学院的特别观察对象。不要离开星环城，不要对任何人提起遗迹里发生的事。」
- 主角：「为什么？」
- 塞蕾斯蒂娅：「因为你体内的东西，不属于这个时代。而知道它存在的人……越少越好。」
- [演出] 她转身离开，走到门口时停下，没有回头。
- 塞蕾斯蒂娅：「还有——如果再听见什么声音，不要回答它。」

**任务更新：** 1-6 完成 → 主角被列入学院「特别观察名单」。
**转场：** 观察室淡出 → 场景 5。

## 场景 5：学院宿舍·夜 ——「三百年前的档案」（章节结尾演出）

**类型：** 结尾演出（半可操作：走回宿舍为可操作段，收到档案后转演出）。
**地点：** 星环学院·宿舍走廊、主角房间。
**演出注：** 深夜。本章最后一场戏，全部悬念收束到一份档案上。

**分镜：**

1. [夜] 学院宿舍走廊，灯光昏暗。主角推开房门。
2. [镜头] 门口地上放着一个牛皮纸档案袋。没有寄件人，没有邮戳，没有可追踪的送达记录。封口处有一枚已经模糊的五瓣星樱标记。
3. [演出] 主角拆开档案袋，抽出文件。文件抬头：「星环学院档案 · 封存三百年」。
4. [特写] 档案中的照片。照片上的人，与现在的主角极为相似。
5. [特写] 档案最后一页，一行手写文字：「如果你已经开始听见星辰的声音，就不要再相信所有人都记得同一段历史。」
6. [演出] 主角的手停住。窗外，夜空中一颗星星悄然熄灭。
7. [黑场] 字幕：第一章·完。下一章：「学院的夜晚」。

**对白：**

- 主角（心声）：「……这个人，是我？三百年前，我就已经存在了？」
- 主角（心声）：（「不要再相信所有人都记得同一段历史」……这份档案，到底是谁送来的？）

**演出注：** 档案来源本章不揭示。它是第一部前期的重要悬疑线索，后续再与白昼议会、塞蕾斯蒂娅以及星樱计划联系起来。

**章节结束。**
