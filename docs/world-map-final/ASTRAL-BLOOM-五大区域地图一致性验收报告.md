## 二、五大区域检查结果

### 1. 星环城（大陆中央）

- **地理位置**：与总览图一致，大陆中央环形都市。
- **地形结构**：环形都市占满画面，中央穹顶加尖塔，外围建筑已合并，放射道路连续，悬崖边缘阶梯化（修复版三处均已修好）。
- **河流湖泊**：外围有水体与河道，与总览图环城水系大致对应。
- **道路网络**：4 条放射道路出城，分别通向西北、东北、东南、南部，与总览图四条区域连接一致；环形道路连续。
- **建筑布局**：环形结构完整，中心与外围分区合理；**学院校区在图中不易辨认**（已知问题，未修复——白模中建筑体量相近，无法仅凭体量区分学院）。
- **重要地标**：中央穹顶与尖塔对应总览图的金色尖塔与星形广场（白模无颜色，无法核对金色与星形）。
- **视觉风格**：灰白白模，与其他区域白模统一；现代幻想文明。
- **技术图（第二轮新增）**：高程分层图、主要路线图、中央尖塔剖面图、地下设施结构图四张齐全，分区统一为 A 中央尖塔区、B 星环学院区、C 内环居住区、D 外环商业区、E 城外河谷区；年份均为 2026；尺寸均为示意值。残留：尖塔剖面图左侧标高尺 48 米与 60 米位置颠倒（刻度值齐全但顺序错，两次 AI 修正未改动），「12 米」「星核大厅」「入口大门」各出现两次；环形道路画了 4 圈（提示词要求三层，多画一圈）；地下图 B1 右边缘个别极小标注略糊。学院校区在技术图中已明确分区（B 星环学院区）。
- **结论**：地理与结构一致；技术图已补齐，道路坡度与通行性仍需 Unity 实机验证。

### 2. 雾海边境（大陆西北）

- **地理位置**：西北山地；右下角露出星环城弧线（东南方向，正确）。
- **地形结构**：高低起伏山脉、峡谷、雾海河谷、阶梯台地；桥梁连接高地；地形过渡自然。
- **河流湖泊**：冰封河谷与水体沿低地分布，符合高低地势。
- **道路网络**：废弃铁路连续（车站、隧道、轨道、列车均有），断桥两端有桥墩与道路连接；山地道路有绕行路线。
- **建筑布局**：车站、隧道口、圆形遗迹（左下，几何对称）、左上古代遗迹群。
- **重要地标**：**无塔版已解决 lineage 问题**：原宝塔位置改为雪山山脊加空圆形台地，全图无任何宝塔、塔楼、高塔建筑；最高元素是自然山峰。古代遗迹（左）、环形柱廊遗迹（左下）、悬崖聚落保留。
- **视觉风格**：灰白材质区分白模（白雪、冷灰岩、微冰蓝冻水、金属），与 fixed 图一致；阶梯式台地、谷底雾气。
- **残留偏差**：原塔址的圆形台地现为空圆形广场，略显空旷；各桥均完整连接，没有一座肉眼可辨的“断桥”（与原 fixed 图处理相同）；顶部中央台地仍有局部较陡的垂直崖面（与原图同类问题）；河流冰蓝色比原 fixed 图稍明显，但仍在“微冰蓝冻水”范围内。
- **结论**：无塔版与总览图西北方向一致，雾海边境现有一张独立的、无塔的区域图；“一图两用”问题已解决（见第三节第 1 条）。旧 fixed 版与 terrain-refined 版保留在 docs 目录，terrain-refined 仍是白塔 lineage 的底图。

### 1. 雾海边境与白塔遗域的身份问题（本次发现的最重要跨区域问题）

### 3. 地形连续性

- 五大区域交界处无法从单张独立地图直接验证：各区域图是独立裁剪的俯视图，没有共享坐标网格，边缘无法逐像素对齐。

### 4. 道路系统

- 区域图统一为灰白白模（材质灰度区分），总览图为全彩概念图——这是项目既定分工（总览定方向、区域白模定空间），不是不一致。

### 7. 实际开发可用性

- 所有地图均为区域空间概念参考与设计示意图，**没有一张能证明**真实高程、实际坡度、道路通行性、碰撞、NavMesh、建筑入口可用性、地下空间连通性。

### 2. 构建中发现并修复的两个真实缺陷

- **地形全品红**：第一批截图全部地形渲染成纯品红，原因是构建版缺少默认地形 shader（`Nature/Terrain/Standard`），与 2026-11-16 的 UI 品红问题同类。修复：`WorldMapBuilder.cs` 新增 `BuildTerrainMaterial()`，用 `Shader.Find` 烘焙 `Assets/WorldMap/Materials/TerrainStandard.mat` 并设为 5 块地形的 `materialTemplate`。修复后 11 张截图品红像素为 0。
- **alphamap 全雪**：品红修复后的截图全部是单调淡蓝白色，原因是 `TerrainData.SetAlphamaps` 在 `CreateAsset` 之前调用时保存后不持久化（保存出的资产带回默认全 L0 雪）。修复：CreateAsset 后重新 SetAlphamaps + SetDirty + SaveAssets。修复后 alphamap 抽样正常（星环城草地 3581/4096、永夜林地 2660/4096、苍穹工业 2283/4096、古树处樱花粉 73 格），截图出现真实色彩。
