# Unity 后续验证清单

**项目**：ASTRAL BLOOM — 星樱物语
**日期**：2026-11-18
**对应报告**：《ASTRAL BLOOM — 艾斯特拉大陆五大区域地图一致性验收报告》

以下内容**没有任何一张现有地图能证明**，全部需要在 Unity 实机中验证。不得仅凭俯视效果图宣称已完成。

## 一、地形与移动

- [ ] 各区域地形高度是否与高程图示意值大致吻合（白塔、苍穹有高程图；星环城、永夜之森无高程图，需先建地形再测）
- [ ] 实际坡度是否可走（尤其白塔台地、苍穹阶梯平台、永夜之森山谷）
- [ ] 悬崖是否有绕行或跨越方式（白塔断裂石桥、苍穹深层峡谷、永夜之森陡崖）
- [ ] 区域间地形边界过渡是否自然（星环城与四大区域交界处）
- [ ] 区域间河流是否连续（白塔冰封河谷、苍穹山间河流、永夜之森湖泊河流）

## 二、道路与导航

- [ ] 一级主干道是否连续可走（星环城 ↔ 四大区域，四个方向）
- [ ] 区域间道路接续点是否对齐（各区域图边缘出口无统一坐标，需实测）
- [ ] 区域内部道路是否连续（白塔环路与观测路线、苍穹工业主干道与高架轨道、永夜之森林间道路）
- [ ] 桥梁是否真正连接两端地形（有碰撞、可通行，非装饰）
- [ ] 隧道是否有明确入口、可进入（白塔左下隧道口、苍穹山体隧道、永夜之森地下入口）
- [ ] 山地道路坡度是否合理（盘山道、阶梯、坡道）
- [ ] NavMesh 烘焙是否覆盖全部可走区域
- [ ] 碰撞体是否完整（建筑、山体、桥梁、护栏）

## 三、建筑与入口

- [ ] 重要建筑是否有合理入口（白塔主入口、苍穹能源塔主入口、中央能源核心、永夜之森星樱遗迹）
- [ ] 白塔与苍穹能源塔的区分是否足够（两者同为宝塔式，需用材质与细节区分）
- [ ] 星环城学院校区是否可辨认（白模中不易辨认，需在 Unity 中用建筑与标识区分）
- [ ] 苍穹中央能源核心作为独立建筑是否足够明确（总览图中不够明显）
- [ ] 工业平台是否有合理地基与支撑（无悬空平台）

## 四、地下空间

- [ ] 白塔地下 B1/B2 是否与地表入口连通（四个入口：塔基、圆形广场下方、工业建筑群下方、左下隧道口）
- [ ] 苍穹地下 B1/B2 是否与地表入口连通（塔基、生产区下方、研究设施附近、山体维护通道、聚落应急入口）
- [ ] 地下主通道、楼梯、直井/升降井是否可走
- [ ] 永夜之森地下记忆保存设施入口是否可进入（尚无地下技术图，需先设计）
- [ ] 地下空间与剖面图的垂直交通关系是否一致

## 五、剧情与玩法空间

- [ ] 第一部七个永夜之森剧情地点是否有足够空间（森林外围、古老森林深处、森林湖泊、星樱遗迹外围、星樱古树、地下记忆保存设施、星樱系统核心区域）
- [ ] 白塔遗域剧情地点空间（白塔、圆形观测广场、古代遗迹群、山顶观景台）
- [ ] 战斗区域是否有合理活动范围
- [ ] 隐藏区域是否有进入方式（白塔隐藏支线、苍穹山体维护入口、永夜之森隐藏山谷）

## 六、区域间加载与过渡

- [ ] 区域间加载与过渡是否顺畅
- [ ] 区域边界是否有可见的接缝或断层
- [ ] 大陆主干道跨区域段是否连续
