## VRoid 角色侧评估（第四个参考，~16:10 CST）

**仓库**：`~/workspace/vroid-avatar-studio-reference/`（21M，MIT，Unity 6 Built-in）。运行时角色形象页：VRoid Studio 导出的 .vrm 丢进 StreamingAssets，捏脸（形态键滑条）、换装、换肤、动作预览（内置程序化待机/摇摆/鞠躬/点头/挥手 + Resources/Motions 的 Humanoid 剪辑自动重定向），头发/裙摆用 VRMSpringBone 弹簧骨布料物理，UI 纯代码运行时生成。

**核实结果**：
1. **UniVRM 能接入**：`Packages/com.vrmc.gltf` + `com.vrmc.univrm` 以 embedded package 形式自带（0.131.1，unity 2021.3+），不需要联网下包；含 Built-in RP 的导入/导出器，MToon shader 在包内。我们的 Unity 6000.0.85f2 Built-in 版本兼容。加载方式是运行时 `VrmUtility.LoadAsync(path)`。
2. **toon 渲染路径可配合**：MToon 是 UniVRM 自带的 Built-in toon shader（带描边、rim、matcap），与我的 AstralToon 可以共存（不同材质各用各的 shader）；视觉上需把 MToon 的 shade 色调到群青配色才能统一。VRMSpringBone 只对 VRM 骨架的骨链生效（头发/裙摆），对现在的几何体角色无效——弹簧骨的价值要等有了 VRM 角色才兑现。
3. **不建议现在就加依赖**：仓库里没有任何 .vrm 模型（README 明确不入库）。没有模型可测就加 UniVRM 是盲目加依赖。等用户用 VRoid Studio 导出 .vrm（选 VRM 0.0）后再接：复制 vendored 包 → 导模型 → 核 MToon 观感 + 弹簧骨 → 接入 ProtagonistSelect/Exploration。

**红线确认**：人物不改——任何 VRM 角色必须按现有角色设计（塞蕾斯蒂娅等 2D 设计）做，不重新设计角色；我没有编造或下载任何角色模型。**需要 .vrm 文件：请用户用 VRoid Studio 按现有角色设计导出 .vrm（VRM 0.0），放到 `Assets/StreamingAssets/Avatars/`。**
