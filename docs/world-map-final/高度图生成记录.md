## 一、诚实前提

- 高程图是 AI 生成的 2D 设计图，**不是实测高程数据**；图上自己写着“高程为设计参考值，非实测数据”。从色带反推的高度只是近似值，只能做到“按地图布局和相对高差重建”，**不能声称是精确地形**。
- 每张高程图只有 6 个色带，采样出来是阶梯状，必须高斯平滑去阶梯感。
- 雾海边境原本没有高程图，本次按无塔版白模 + 总览图新生成了一张（`astral-bloom-wuhai-border-elevation.webp`，两 docs 目录各一份，色带见下表）。

## 二、管线方法

1. **裁剪**：去掉标题栏（上 10%）和页脚（下 8%），取图体 `x 0.02–0.98, y 0.10–0.92`，尺寸 1843×1049，长宽比 1.757。
2. **重采样**：双线性插值到 513×513 网格（Unity Terrain 高度图标准尺寸）。
3. **色带匹配**：每个像素找最近的 6 个目标 RGB（欧氏距离），距离 > 60 视为非地形（文字、道路、等高线、建筑、图例），不匹配。
4. **去污染**：图例框、深蓝标注底框等会误判的色块用矩形 mask 强制设为未知（见第四节）。
5. **插值**：未知像素先最近已知点填充，再用 sigma=15 高斯模糊场做平滑插值（已知像素保持原值）。
6. **特殊修正**：苍穹中央能源塔平台按图上标注（能源塔平台 1120 m）强制为橙色带（1100 m）椭圆区，见第四节。
7. **平滑**：高斯滤波 sigma=3（513 网格像素单位），去阶梯、保留大尺度起伏。sigma=6 对比过：河谷会被洗掉，sigma=3 更清晰且无肉眼可见台阶。
8. **输出**：16 位小端 RAW（`*_513.raw`，526,338 字节 = 513×513×2），**第 0 行 = 南 = 图片底行**（已做上下翻转，Unity RAW 导入时第 0 行对应 z=0）；色带着色预览图 `*_513_preview.png`（北在上）；色带匹配图 `*_513_bandmap.png`（未知=白色）；元数据 `*_513_meta.json`。

**高度归一化**：`h_norm = 色带高程 / 区域最大高程`；Unity 地形高度 = 区域最大高程（米）。苍穹色带是区间值，取区间中值（深蓝 300、浅蓝 500、绿 700、黄 900、橙 1100、红 1300），最大高程 1400 米。

## 六、给 Unity 的地形参数

- **网格**：513×513，RAW 16 位小端，第 0 行 = 南。
- **单块尺寸建议**：宽 2000 m × 深 1138 m（长宽比 1.757，与裁剪一致；**不要拉成 2000×2000 正方形，会把地形沿 z 向拉长 1.76 倍**）。
- **地形高度**（= 区域最大高程）：白塔 420 m、苍穹 1400 m、星环城 100 m、永夜之森 300 m、雾海边境 600 m。

## 七、残留问题与近似性说明

1. 所有高度均为设计参考值重建，不是实测地形；相对高差与布局可信，绝对数值不可当施工数据。
2. 苍穹中央山谷、星环城建筑区、雾海边境车站区等白色无色带区域为插值重建，非原图直接采样。
3. 河流、湖泊位置以高程图低洼处为准；水面高度需按地形低点另定。
4. 古树、金尖塔、能源塔、白塔等地标建筑不在高度图里，需在 Unity 里另建模型放置。
5. 断桥、隧道口等地形断点在高度图上是连续的（高程图不断开），如需断桥效果要在 Unity 里另行处理。
