# 角色建模规范 — 塞蕾斯蒂娅 · Celestia（第一位正式 3D 角色）

> 决定：2026-11-18 ~17:43 CST，用户选定 VRoid 路线——VRoid Studio 制作角色，导出 VRM 0.0，再接入 Unity。
> 几何体角色（TideSong 代码拼的胶囊+球体）只作临时占位，不作为最终角色表现。
> 分工：用户在自己电脑的 VRoid Studio 里制作并导出 `.vrm`；助手负责接入 Unity 后的加载、骨骼、物理、动画、光照验证。
> 设计基准：本规范以现有塞蕾斯蒂娅 2D 立绘为准（`unity/Assets/Resources/Characters/celestia_splash.png`，游戏内 5★  splash），不重新设计角色。
> 故事设定见 `docs/story-bible-main.md` §塞蕾斯蒂娅（星轨观测局首席观测者，星属性，守护蓝色星核，等了 300 年）。

## 一、角色标准（以立绘为准，不改设计）

- **身份**：女性二次元角色，星轨观测局首席观测者；气质清冷、温柔、略带忧郁，视线微垂。
- **头发**：银灰长发，过腰，带流动感；发尾带淡蓝色；前额碎发 + 两侧长鬓发 + 一根呆毛。
- **眼睛**：淡蓝色大眼，眼神温和下垂；眼白干净，虹膜带高光。
- **服装**：银白外层（长外套/披风式，带金边）+ 群青内衬长裙；胸前星形罗盘徽记；裙摆带浅色星樱纹样；腰间挂星核稳定器（方形仪表，圆形蓝色发光表盘）；黑色打底裤/长靴；肩部有金色月牙纹。
- **配饰**：星形头饰——细金环绕头，带星形尖角与蓝色宝石；耳坠细长。
- **身材**：成熟的日式二次元游戏角色比例（约 1:6.5–1:7 头身），不要 VRoid 默认模板的廉价感：头相对小、肩窄、腿长、腰线高。

## 三、VRoid Studio 制作参数

### 1. 脸
- 脸型：瘦长、柔和，下巴略尖；不要默认圆脸。
- 眼睛：自定义眼纹理（按立绘手绘，不要用默认眼）：淡蓝虹膜、上眼线细、眼尾略下垂；双眼皮线浅。
- 眉毛：细、淡银灰、略平。
- 鼻子/嘴：鼻子只留淡影；嘴小、淡粉 #D9A0A8，微抿。
- 耳朵：正常比例；耳坠用配饰另做。

### 2. 头发
- 长度：过腰长直发，后梳；前额碎发分层，两侧鬓发垂到胸前。
- 颜色：主色 #E8ECF2，阴影 #B9C4D6，发尾渐变 #7FA8D9（VRoid 发色支持渐变/高光层）。
- 发型细节：顶部蓬松、发束分明；一根呆毛在头顶偏右。
- 可选：Etsy 的 "Vroid Straight Hair Preset: Cute Girl, Two Side" 是付费发片预设，可作长直发起点，再按本规范改色改长——不强制买，VRoid 自带长发预设也能做。
- 弹簧骨：后发、两侧鬓发分别设 spring bone（刚度中等、重力略低、阻尼适中，头发飘动不穿模）。

### 3. 身体
- 身高：约 165 cm（VRoid 身高滑条按 1:6.5–1:7 头身调）。
- 体型：肩窄、腰细、腿长；胸部适中，不要夸张。
- 肤色：#F6E8DC，肤色滑条偏白一档。

### 4. 服装（VRoid 服装 + 自定义纹理）
- 外层：白色长外套（用 VRoid 长外套/连衣裙为底），导入自定义纹理：金边、肩部月牙纹、裙摆星樱纹样。
- 内层：群青连衣裙，胸前星形罗盘徽记用纹理画在胸口位置。
- 腰间星核稳定器：VRoid 做不了复杂硬表面——先做简化版（腰包挂件 + 蓝色圆形纹理表盘）；精细版后期在 Blender 补充建模，再并入同一模型。
- 鞋：黑色长靴。

### 5. 配饰（VRoid 配饰系统，复杂件 Blender 补）
- 星形头饰：细金环 + 星形尖角 + 蓝宝石——VRoid 配饰做简化版（金环+星形挂件）；精细版 Blender 补充。
- 耳坠：细长银链 + 小蓝宝石。

## 四、VRM 0.0 导出检查清单

导出前逐项打勾（VRoid Studio → Export → VRM）：

- [ ] 版本选 **VRM 0.0**（不是 1.0；项目 UniVRM 0.131.x 走 VRM 0.x 管线）
- [ ] 标题：`Celestia`；作者：按你的署名；许可信息填好
- [ ] 弹簧骨：后发、两侧鬓发、裙摆已设，且不穿模（VRoid 预览里晃动头部检查）
- [ ] 表情 BlendShape：Blink（眨眼）、Joy、Sorrow、Angry、Surprised 至少有 Blink + Joy + Sorrow
- [ ] 视线：眼睛可动（LookAt 骨骼正常）
- [ ] 模型无破面、无多余隐藏部件；纹理已全部内嵌（不要外链）
- [ ] 文件名：`celestia.vrm`；放到 `Assets/StreamingAssets/Avatars/`（发给助手后由助手接入）
- [ ] 在 VRoid Studio 里播一次待机动作，确认头发/裙摆物理不抽风

## 五、接入游戏检查清单（.vrm 到手后，助手负责）
